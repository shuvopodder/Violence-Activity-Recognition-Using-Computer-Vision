# Violence Activity Recognition Using Computer Vision

An automated surveillance system designed to detect violent and criminal activities from real-time CCTV video feeds using computer vision and deep learning. When an incident—such as a physical fight, burglary, hijacking, or car accident—is detected, the system automatically captures a real-time snapshot and alerts the nearest authorized personnel for immediate action. 

Designed as a core component of a Smart Surveillance System, this solution enhances public safety and can be easily adapted for offices, factories, construction sites, and healthcare facilities.

> **Project Documentation:** This project was completed as a final-year BSc in CSE research project requirement. All related reports, presentations, and demo videos are available on the [Project Website](https://sites.google.com/diu.edu.bd/smart-ai-cctv/home?authuser=0).
